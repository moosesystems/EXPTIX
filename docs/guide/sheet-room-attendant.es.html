Empieza tu turno

  1. 🟢 Abre My work (mi trabajo). Marca On shift (en turno).
  2. 🛏️ Toca My rooms (mis habitaciones). Estas son tuyas.
  3. 🟨 ¿Borde dorado? Un huésped llega hoy. Límpiala primero.
  4. ⚡ ¿Urgente (Rush)? Límpiala ahora.

Colores de las habitaciones

Color Significa
🟥 Rojo Sucia
🟧 Naranja Limpiando ahora
🟦 Azul Limpia
🟩 Verde Revisada. Lista para un huésped.

Iconos pequeños: ⭐ huésped VIP. 🚫 No molestar. 🧹 El huésped quiere limpieza. 🔧 Algo para reparar.

Limpiar una habitación

  1. 👆 Toca la habitación.
  2. ▶️ Toca Start cleaning (empezar limpieza). La habitación se pone naranja.
  3. 🧽 Limpia la habitación.
  4. ✔️ Toca Clean (limpia). La habitación se pone azul.

El huésped dice que no

  • 🚫 ¿No tocar la puerta? Marca DND (no molestar).
  • 🌿 ¿Sin limpieza hoy? Marca Declined service (servicio rechazado).

Algo está roto

  1. 👆 Toca la habitación.
  2. 🔧 Toca Report a problem (reportar un problema).
  3. ✍️ Di qué está mal. Agrega una foto.
  4. 📨 Toca Create request (crear solicitud).

Un huésped olvidó algo

🧳 Toca ☰, Lost and found (objetos perdidos), + New (nuevo). Di qué es y dónde estaba. Dáselo a tu supervisor.

Si algo está mal

  • 😕 ¿No puedes entrar? Pregunta a tu supervisor.
  • 🔕 ¿El teléfono no suena? Marca On shift.
  • 🚨 ¿Fuego o peligro? Llama al 911 primero.

Por qué te ayuda: tus toques muestran tu buen trabajo. Nadie te marca tarde por una habitación donde no podías entrar.
