## Know the limits before you start

- One property per install today. Groups run one install per property.
- App screens are English only today. Printed guides can be translated now.
- No single sign-on yet, and no app-store app (it installs from the browser).
- The Opera Cloud and Canary links are beta and untested against live systems.
- Tested with a 182-room demo hotel. Large properties pilot first.
- Free software with no vendor support contract. Support comes from your own IT, an IT provider you choose, or the community.
