Why it exists

A hotel runs on hundreds of small jobs a day.

Without one shared place, those jobs live in radio calls, sticky notes, phone messages and people's heads. Things get missed between shifts. Guests ask twice. Nobody can answer "how fast do we fix things?"

ExpTix gives every department one list. Anyone can say "this needs doing". It routes the job, starts the clock, nudges people, escalates when it slips, and remembers everything.

📻 "Can someone check 514's heat?" lost
📝 Sticky note: towels for 706 fell off
📞 Third call about the same leak angry guest
🤷 "Who fixed the fryer last time?" no idea
🎫 One ticket, right team, SLA running, full history ExpTix
Features

Built for the whole property, not just the front desk.

Eleven departments, eight roles, one system. Everything you need on day one, nothing you have to bolt on.

🎫

Tickets with teeth

Auto-routing from plain language, SLAs with warning, breach and escalation, checklists, labour, parts, photos and follow-up tasks for other teams.

🛏️

Live housekeeping board

Every room at a glance. Credit-based auto-assignment, DND, rush, declined service, out of order, inspections and minibar posting.

🔧

Engineering and PM

Assets, preventive maintenance that opens its own tickets, parts and stock, vendors with insurance expiry, purchase requests with approval.

🌡️

Food safety (HACCP)

Temperature logging by hand or sensor. Out-of-range readings open an urgent kitchen ticket. 86 list, allergy alerts, BEOs.

📱

Guest QR portal

A code in every room. Guests ask, track and rate without an app or a sign-in. Low ratings alert the front office.

🛡️

Security and incidents

Incident reports, key control, lost and found, and a hash-chained audit log that proves nothing was changed after the fact.

🔔

Notifications that land

In-app, web push, email, SMS, Teams, Slack and signed webhooks. Rules decide who hears what, by department, priority and event.

🤖

AI-ready from the start

A built-in MCP server lets Claude and other assistants brief a shift, triage requests and update work, under the same permissions as staff.

Every ticket tells the story

Who asked, who took it, what was done, how long it took and whether it met the promise. Guests get a live tracking link.

HACCP without the clipboard

Every cooler, freezer and hot box with its safe range and next check. Sensors post readings on their own.

Volume, response and resolve times, SLA misses, labour and parts by department. Guest ratings, PM on time, inspection scores.

Security you can show an auditor

A live control map against NIST SP 800-53 Rev. 5 and SP 800-63B, with the real numbers behind each control.

  • Argon2id, lockout, TOTP MFA
  • Scoped, hashed API tokens
  • Tamper-evident audit chain
Mobile first

In every pocket. No app store.

ExpTix is a progressive web app. Staff add it to their home screen and get push notifications, a bottom tab bar and big touch targets made for gloves and busy hands.

Guests scan the code in their room and ask for towels, a late check-out or a repair in two taps, then watch it happen.

  • Works on Android, iPhone, tablets and desktops
  • Web push on iOS 16.4+ and every modern browser
  • Guest portal needs no account and no download

Open by design

An API for everything. An MCP server for AI.

Every screen sits on a documented REST API with an OpenAPI 3.1 spec. Wire it into your PMS, BI tools or automations. Point an AI assistant at the MCP server and let it write the morning briefing or triage overnight messages.

  • Scoped tokens act with a real user's role
  • Signed inbound and outbound webhooks
  • Every integration has a mock mode for demos and testing
Get started

From clone to demo hotel in five minutes.

PHP 8.1 or later. No framework, no build step, no Composer. SQLite for a trial, MySQL for production.

git clone https://github.com/moosesystems/EXPTIX.git exptix
cd exptix
php app/bin/cli.php migrate
php app/bin/cli.php seed      # fictional 182-room hotel, prints the passwords
php -S localhost:8080 -t public public/index.php

Open localhost:8080 and sign in as gm with the demo password.
